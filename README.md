# Blinkit-data-analysis-project

## Project Overview
This project analyzes Blinkit grocery data using Microsoft Power BI. The dashboard helps understand sales performance, product categories, and business insights through interactive visualizations.

## Objectives
- Analyze total sales and business performance.
- Compare sales across product categories.
- Identify top-performing products.
- Analyze sales trends across different periods.
- Present key business insights using an interactive dashboard.

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Sales
- Total Cost
- Total Profit
- Profit margin

## Dashboard Features
- Interactive charts and graphs
- Sales performance analysis
- Category-wise comparison
- Financial year analysis
- KPI cards for key metrics

## Skills Demonstrated
- Data cleaning and transformation
- Data modeling and relationships
- DAX measures
- Report design
- Interactive dashboard development

## Conclusion
This project helped me improve my Power BI and data analysis skills. The dashboard presents business data in a visual format to support better decision-making.
